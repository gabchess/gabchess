## 🧩 Augments

An augment is a folder that teaches an AI assistant a whole job. Plain english: onboarding docs for an AI employee, plus the guardrails that stop it from cutting corners, zipped so anyone can install it.

Every augment here is three parts:

&rarr; **Skills** = the SOPs. Step-by-step playbooks the AI follows for each task.<br>
&rarr; **Hooks** = the guardrails. Automatic checks that block the AI the moment it breaks a rule, instead of trusting it to remember.<br>
&rarr; **README** = the manual. A stranger installs and runs the whole thing w/o me in the room.

These are private rn, no links. Ask me. Prospector up in the GTM section is the open one; fork it.

## 🔍 Security research

A high-severity bug in Anchor's LazyAccount code, v0.31.0 to v0.32.1. `Lazy::size_of` measured a `[T; N]` array by its first element times N. Every field after an unsized-type array loaded from the wrong byte offset, and `exit()` wrote the corruption back. [Writeup, PoC, fix](https://github.com/gabchess/anchor/pull/1). Upstream shipped [the same fix](https://github.com/otter-sec/anchor/pull/4319) five weeks later. Bounty paid.

Also built the [Solana Vault Standard Extension](https://github.com/gabchess/solana-vault-standard/tree/feat/svs-7-native-sol-vault) for a Superteam Brazil bounty. SVS-7 was the round's reviewer pick, then lost to a full-stack entry.
